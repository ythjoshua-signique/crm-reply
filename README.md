# 고객응대 CRM 스킬

고객 문의를 받는 업체를 위한 Windows Codex 스킬입니다. 예약제 매장, 교육기관, 쇼핑몰, 대행사 등에서 문의를 분류하고 답장 초안, 담당자 확인사항, CRM 기록을 만듭니다.

Windows Codex에서 이 폴더의 SKILL.md를 열고 “이 스킬로 가상 상담 한 건을 처리해서 답장과 CRM 기록 파일을 만들어줘”라고 요청합니다. 프로젝트에서 `$crm-reply`로 호출하려면 이 폴더를 프로젝트의 `.agents/skills/crm-reply`에 복사한 뒤 프로젝트를 다시 엽니다.

[가상 사진관 예약·가격 문의](demo/inquiry.json) → [답장 초안](demo/reply.md) 및 [CRM 기록](demo/crm-record.json). 무료판은 한 건씩 처리하며 결과를 로컬 파일로 저장합니다.

## 유료판 CRM 연결 설계

업체별 운영시간·가격·환불 등 승인된 안내를 반영해 상담 화면에서 답장 초안을 만들고, 담당자가 검토·수정·승인할 수 있게 연결합니다.

유료판 CRM 연동은 개발 중입니다. 무료판은 이 저장소의 **Code → Download ZIP**에서 받을 수 있습니다.
